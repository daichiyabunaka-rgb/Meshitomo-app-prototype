# ともつく！共有Supabaseプロジェクト移行（飯とも！側の対応）

2026-11-12、飯とも！（meshitomo）をシリーズ共通のSupabaseプロジェクトへ移行した。
 proposal 002（tomotsuku-memo の `proposals/`）で保留になっていた案だが、
 猫とも（ニーアキャット）追加と合わせて足並みを揃えるため実施した。

## 構成（犬とも!・釣りとも!・ニーアキャットと同一方式）

- **appId = `meshitomo`**（`AppConfig.appId`）
- **profiles は「ユーザー × アプリ」の複数行構成**（複合PK `(id, app_id)`）。
  同一メールアドレスのアカウントは全シリーズでそのままログインでき、
  アプリごとに別のプロフィール行を持つ
- 募集（recruitments）/ コミュニティ（communities）/ イベント（events）/
  チャット部屋（chat_rooms）/ カテゴリ（categories）の読み書きに
  `app_id` を付与・フィルタ（他アプリのデータ混入防止）
- `get_or_create_dm` RPC に `p_app` を渡す（新署名）
- Storage のアイコンパスは `<uid>/meshitomo/` 配下（共有 `icons` バケット）
- **ともつく！連携**（0003相当）:
  - `profiles.cross_app_visible`（全体公開スイッチ）を
    マイページ →「ともつく！連携」でアプリごとに切り替え可能
  - 近くの人は「自アプリの行 ＋ 他アプリの横断公開行」を表示し、
    同一ユーザーは重複除去。他アプリユーザーにはバッジ（例: 犬とも！から表示）
  - 他アプリユーザーとのDMは `app_id='cross'` の部屋で作成

## データベース側

DBマイグレーションは tomotsuku-memo（プライベートリポジトリ）の
`schema/migrations/` で番号付き管理する（proposal 006 の運用）。
飯とも！の移行に必要な変更は **0001〜0005 にすべて含まれており、
2026-11-12 時点で共有プロジェクトの Dashboard（SQL Editor）から適用済み**。

| マイグレーション | 内容 | 備考 |
|---|---|---|
| 0002_multiapp.sql | app_id列・profiles複合PK・get_or_create_dm新署名 | DEFAULT 'inutomo'（旧APK互換） |
| 0003_cross_app.sql | profiles.cross_app_visible | 横断公開 |
| 0004_services_master.sql | services参照マスタ（シードに meshitomo 含む） | 総合版・API化の前提 |

飯とも！独自のテーブル・列（stores系 `store_type` 等）は 0001_init.sql の
旧マスターに元々含まれているため、追加のマイグレーションは不要。

## ビルド

共有プロジェクトの接続情報を渡す:

```
flutter build apk --dart-define=SUPABASE_URL=https://hlcsuogoghrgqabkaqxm.supabase.co \
                   --dart-define=SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
```

未指定の場合は従来どおりモックモード（端末内データ）で動作する。

## 旧プロジェクトの扱い

これまで飯とも！が単独で使っていたSupabaseプロジェクトのデータ移行
（既存アカウント・募集・コミュニティのインポート）は未実施。
必要になった場合は `profiles` 行に app_id='meshitomo' を付与して
INSERT すれば良い（auth.users 側はプロジェクトをまたいで移せないため、
アカウントは再登録が基本方針）。
